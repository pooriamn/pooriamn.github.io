# pooriamn.github.io

Source for my personal site, [pooriamn.github.io](https://pooriamn.github.io/). Plain HTML and CSS, served by GitHub Pages.

The arcs in the header are impedance spectra of a resistor in parallel with a constant-phase element, Z = R / (1 + (jωτ)^α), drawn for α from 1 down to 0.55. More of that in the [Electrochemical Engineering Toolkit](https://github.com/pooriamn/electrochem-toolkit).
